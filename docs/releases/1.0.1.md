# StageLab Native 1.0.1

稳定性与多窗调度修复版本 / Stability & multi-window bugfix release.

### 更新内容 / What's Changed

- **关闭窗口清理记忆**：关闭或移除应用窗口后自动清除已保存的窗口尺寸、横竖屏位置与迷你悬浮状态，且自动并排排版不再覆盖默认记忆；重新打开应用时以默认状态启动。
- **修复切换与平铺并发重叠**：同步 Dock / 广播合并与 `SWITCH_SHOW` 工作区切换时序，并修复 Dock 拖拽更新最近应用列表时的 `SystemUI` 主线程并发 `NullPointerException`。
- **修复部分应用铺满遮挡与状态锁死**：安全清理 ColorOS `startChangeAnim` 在无尺寸变化场景下残留的 `flexibleTaskChanging` 状态锁（如 Reddit 等应用），并加入多窗平铺收敛重试校验。

---

- **Clean window memory on close**: Clear persisted window geometry and mini-floating state when closing an app window, and skip persisting programmatic auto-tiling frames.
- **Fix switch-show / tiling race & Dock crash**: Synchronize stage switch completion with tiling callbacks and keep `recentPackages` mutations strictly on SystemUI's main handler during Dock drag-and-drop.
- **Recover ColorOS changing-state lock**: Safely clear leaked `flexibleTaskChanging` / `customTransitionType` flags on idle tasks (e.g. Reddit) and add bounded tile convergence retries.
