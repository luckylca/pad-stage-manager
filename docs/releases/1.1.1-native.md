# StageLab Native 1.1.1-native

- Migrate the Android application ID to `io.github.luckylca.stagelab` for LSPosed Module Repository submission.
- Update module self-detection, broadcast actions, recovery commands and installation documentation to match the new ID.
- Existing users must disable the old module, reboot, uninstall it, then install and enable the new APK.

功能基于 1.1.0-native；本次主要调整正式发布包名。旧版需先禁用、重启、卸载，再安装启用新版。
