# StageLab Native 1.0.0

首次正式发布 / Initial stable release.

- Native multi-window Stage Manager for Android tablets and foldables.
- Orientation-adaptive workspace layouts, recent stages, Dock and app search.
- Drag-and-drop workspace management and built-in hook diagnostics.
- Official application ID: `io.github.luckylca.stagelab`.

旧测试版本迁移：先禁用旧包名 `dev.stagelab.nativehook` 的模块并重启，再卸载旧版、安装并启用新版。若已安装新包名且 versionCode 大于 1 的测试包，也需先卸载。
