## StageLab Native 1.1.0-native

适用于 Android 13–17 平板与折叠屏设备（支持 ColorOS / OxygenOS / realme UI 原生浮窗与 AOSP Freeform 自动回退）的原生级 **iPad Stage Manager（台前调度）** LSPosed 模块。

### 本次发布内容
- **原生多窗口工作区（Stage）与自由平铺**：基于 `ShellTaskOrganizer` / `WindowContainerTransaction` 与 ColorOS `FlexibleWindowManager` 调度真实系统任务窗口；横屏支持 2～3 窗并排等宽，竖屏自动转为全宽上下堆叠行布局，旋转屏幕后自动恢复 `scale = 1.0` 并分别记忆横竖屏窗口尺寸。
- **左侧 3D 最近工作区栏与 120fps 神奇移动过渡**：实时拉取系统 `TaskSnapshotManager` / `ActivityTaskManager` 高清缩略图（自动避让 `FLAG_SECURE` 隐私窗口），点击切换工作区、向内拖拽合并入当前工作台。
- **底部毛玻璃 Dock 与零延迟物理弹簧应用搜索（`⌕`）**：预暖常驻 `HAS_DRAWN` 窗口支持任意动画时刻毫秒级打断；长按应用搜索或直接从 Dock 图标拖拽即可完成 Dock 指定位置让位固定、水平排序、拖动移除，以及直接拖放至当前工作区或左侧 3D 卡片合并。
- **安全与生命周期隔离**：锁屏自动拆离悬浮层并在解锁后恢复重绘；关闭台前调度开关立即释放全部系统 Hook 门控，不残留桌面或手势拦截。
- **Material You 图标与多版本兼容性诊断页**：内置 `system_server` / `SystemUI` 全部 Hook 探针状态检查（命中 / 回退 / 缺失）及一键复制诊断报告。

### 兼容性与真机实测
- **系统支持**：Android 13 – 17（API 33 – 37），`minSdk = 33`，`targetSdk = 36`
- **框架要求**：LSPosed / Vector（`xposedminversion = 82`）
- **实测基准设备**：OPPO Pad mini（`OPD2515`），ColorOS `V17.0.0`，Android 17（API 37）

### LSPosed 作用域（Scope）
- `system`（系统框架）
- `com.android.systemui`（系统界面）
- `com.android.launcher`（系统桌面）

### 安装与验证
1. 安装 `StageLab-Native-1.1.0-native.apk` 并在 LSPosed / Vector 中启用模块。
2. 确认作用域已勾选上方 3 个系统组件，随后软重启或重启一次设备。
3. 打开 **StageLab Native** 并开启 **启用台前调度** 开关即可使用；若需快速关闭，点击常驻通知或返回主界面关闭开关即可。
